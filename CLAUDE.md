# CLAUDE.md

## What this repo is

This is a **personal project**: a knowledge base for Eric's son's youth
baseball team, "OCP". It lives in the LocalCraze GitHub account but has
**nothing to do with LocalCraze** the company — don't assume any business
context.

## Layout

- `TEAM.md` — team overview and coaching staff
- `roster/ROSTER.md` — players, numbers, positions, lineup notes
- `schedule/SCHEDULE.md` — games, tournaments, practice times
- `practice/PRACTICE-PLANS.md` — practice plans and drill library
- `logistics/LOGISTICS.md` — fields, equipment, parent duties, fees, contacts

## Conventions

- This is a docs-only repo (Markdown). No build, no tests.
- Keep files current rather than appending logs — edit tables in place;
  move past-season info to an `archive/` folder if it accumulates.
- These are kids: keep personal information minimal (first names and last
  initials are enough for players; no addresses or birthdates).
- When Eric shares team info in conversation, fold it into the appropriate
  file(s) so it persists across sessions.
