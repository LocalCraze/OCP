# OCP Baseball — Team Knowledge Base

This repository is the knowledge base for the OCP youth baseball team. It's a
personal project (not affiliated with LocalCraze) used to keep everything about
the team in one place: roster, schedule, practice plans, and logistics.

## Structure

| Folder / File | What goes here |
|---|---|
| `TEAM.md` | Team overview: name, league, age group, season, coaching staff |
| `roster/` | Player info: names, numbers, positions, batting order notes |
| `schedule/` | Game schedule, results, tournament info |
| `practice/` | Practice plans, drills, skill development notes |
| `logistics/` | Fields/locations, equipment, snack schedule, contacts, fees |

## How to use

Fill in the placeholder files with real details, or just tell Claude about the
team in a session and it will update these files for you.
